# LISTEN
LISTEN (Legal Issue Spotting in Textual Everyday Narratives) is a local Streamlit app that reads a person's own story of a legal problem and suggests which of 20 LIST categories apply, with word-level explanations The program compares TF-IDF and embedding-MLP classifiers on Learned Hands to show where each fails. 

LISTEN was built by Garret Duo, Lyndon Huang, and Sohum Sarwate as a final project for the COSC 72 course (Accelerated Computational Linguistics) at Dartmouth College for the Fall 2026 quarter.
