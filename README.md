# LISTEN
LISTEN (Legal Issue Spotting in Textual Everyday Narratives) is a local Streamlit app that reads a person's own story of a legal problem and suggests which of 20 LIST categories apply, with word-level explanations The program compares TF-IDF and embedding-MLP classifiers on Learned Hands to show where each fails. Dartmouth COSC 72, Fall 2026.
